# 不允许漂移的合同要求

本文件是用户要求与本次已确认设计方向的集合，不假装新增API已经实现。S0-A核当前事实，S1-A用最小现有结构实现/冻结签名到contracts-current.md；以后只能由S1-E或明确S1返修变更，并给全部消费者适配清单。

| 边界 | 必须表达的语义 | 禁止捷径 |
| --- | --- | --- |
| 单选/多选 | 取消无变更；clear明确清空；selected明确值 | nullable单值同时表示取消和清空 |
| 字段错误 | 持久错误关联字段，首错定位且保留输入 | 只toast、静默tryParse失败变0 |
| 草稿离开 | 未改直接离开，有改可继续编辑/放弃；保存成功解锁 | 所有sheet无条件禁止关闭，或无提醒丢稿 |
| 忙碌 | 所见输入与提交快照一致，对象级防重复/失败可恢复 | 只按钮转圈、其余随便改 |
| 金额隐私 | 现有偏好唯一来源，跨route一致；显示/语义/tooltip/导出分别检查 | 页面局部InheritedWidget新route默认false，双份持久化偏好 |
| 金额精度 | 使用已有formatter/整数分路径；币种与分组正确 | 浮点重新计算财务结果、不同币种直接相加 |
| 未知/状态 | loading/error/unknown/zero/empty各自表达 | 未取到数据显示零或默认成功 |
| 数据范围 | 账本/分组/日期/总量与真实请求一致 | 只过滤当前页假装全局筛选/静默TopN |
| 文本/触区 | 系统TextScaler、44舒适下限与48常用最小尺寸、内容增高 | 全页缩放或限制字号、关键金额ellipsis |
| 输入几何 | FxTextField管理自身边界，无边框金额保留显式合同 | 全局enabledBorder覆盖InputBorder.none |
| 背景反馈 | 图形/文字/实色控件使用正确配对前景/焦点 | 品牌蓝底叠同蓝看不到按压 |
| 权限与安全 | 已核角色枚举、凭证恢复须身份验证，保留验证码/锁保护 | 猜roleId、改密弱化、验证码绕过、存储失败直接解锁 |
| 调度/模板 | 可视化编辑无损保留旧字段与原始调度 | 不认识cron就重置每天09:00，偷偷删模板字段 |
| 文件交付 | 输出bytes/文件名和用户可取动作，取消不同失败 | 临时目录路径toast等于导出完成 |

平台/接口未确认项写external-gaps.md：当前证据、缺哪项、影响哪些ID/阶段、可独立完成的本地工作、不能验收的内容、后续具体验证步骤。不得替用户批准风险或擅自启用已关闭内购。
